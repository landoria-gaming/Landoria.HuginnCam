The native Direct3D 11 encoder is implemented by Landoria and calls the current NVENC C API directly. The MIT-licensed `nvEncodeAPI.h` interface header is distributed by the [FFmpeg nv-codec-headers project](https://github.com/FFmpeg/nv-codec-headers) and retains NVIDIA's original copyright and license notice.

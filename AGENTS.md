# Agent instructions

## Global rules

- At the start of each session, download the latest [global instructions](https://raw.githubusercontent.com/landoria-gaming/agents/refs/heads/main/AGENTS.global.md), read them carefully, and follow them.

## Repository specific rules

- In every Saga Capture camera mode, including `CaptureMode` and
  `PreviewMode`, maximize smoothing of camera rotations, acceleration, and
  deceleration to prevent perceptible jolts. This requirement applies within
  every behavior and across all behavior transitions.
- Remember that the camera is a drone and should fly like one. It can hover in place.
